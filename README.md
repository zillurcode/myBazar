# 🛒 Local Grocery Price (দৈনন্দিন কাঁচাবাজার দর)

A modern, real-time web application built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **DaisyUI** to track and display everyday updated local grocery prices, helping users stay informed about daily market rates.

---

## ✨ Features

- **Real-Time Price Updates:** View everyday updated prices for essential grocery items (rice, vegetables, meat, fish, oil, spices, etc.).
- **Category-wise Browsing:** Easily filter items by categories like Vegetables, Fish, Meat, Spices, and more.
- **Secure Authentication:** User signup and signin functionality powered by **Better Auth** (supporting Email/Password and Social logins).
- **Responsive Design:** Fully mobile-friendly and sleek UI crafted with **Tailwind CSS v4** and **DaisyUI v5**.
- **Database Integration:** Secure and fast data management using **MongoDB Atlas**.

---

## 🚀 Tech Stack

- **Framework:** [Next.js 16 (App Router)](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) & [DaisyUI v5](https://daisyui.com/)
- **Authentication:** [Better Auth](https://www.better-auth.com/)
- **Database:** [MongoDB & Mongoose / Native Driver](https://www.mongodb.com/)
- **Deployment:** [Vercel](https://vercel.com/)
